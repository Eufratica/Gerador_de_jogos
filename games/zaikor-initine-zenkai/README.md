# Zaikor: Initine Zenkai

Projeto 3D de ação e aventura em fantasia sombria desenvolvido de forma incremental em **Godot Engine 4.x Stable** (`Compatibility Renderer`), isolado na PlayForge Factory em `games/zaikor-initine-zenkai/`.

> **Nota de Isolamento:** Este projeto é totalmente independente do jogo-âncora 2D (`Zaikor: Zenkai Infinite`) mantido na raiz do repositório.

---

## Estado Atual (`0.1.0-etapa1`)

- **Etapas Concluídas:**
  - **Fase 0 / Etapa 0 (`0.0.1-phase0`):** Análise real de hardware/ferramentas, governança SDD/OpenSpec, GDD (`25` seções) e `GameSpecification v2`.
  - **Etapa 1 (`0.1.0-etapa1`):** `Godot 4.7.2 Stable` instalada paralelamente em `../../tools/godot-4.7.2/` (`SHA-512` validado), `project.godot` em **Compatibility Renderer** (`1280×720`, perfil `Baixo` padrão), `scripts/core/` puro, cena base 3D (`scenes/main/`), testes headless unitários/integração e primeira medição real na `Intel(R) Iris(R) Xe Graphics`.
- **Próxima Etapa:** **Etapa 2 — Personagem e Câmera 3P** (após confirmação para prosseguir).
